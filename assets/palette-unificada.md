# Paleta Visual Unificada — AI Nexus Core
# Diseñada para que Warp + Open Code se vean como un solo entorno

## Colores base (OLED profundo)
- Fondo base:        #020617  (negro OLED puro)
- Fondo panel:       #030712
- Fondo elevado:     #070c18
- Fondo superficie:  #0a0f1c
- Fondo vidrio:      rgba(3, 7, 18, 0.85)

## Acentos coordinados
- Acento primario:   #22d3ee  (cian neón — Open Code y Warp)
- Acento secundario: #8b5cf6  (púrpura suave — contraste visual)
- Acento hover:      #38bdf8
- Acento inverso:    #020617

## Semántica
- Éxito:     #34d399  (verde esmeralda)
- Advertencia: #fbbf24 (ámbar)
- Error:     #f87171  (coral)
- Info:      #22d3ee  (cian)

## Texto
- Texto base:   #f8fafc
- Texto muted:  #94a3b8
- Texto inverse: #020617

## Bordes y divisores
- Borde base:     #1e293b
- Borde activo:   #22d3ee
- Borde sutil:    #1e293b

## Animaciones (Warp)
- Blur:           backdrop-filter: blur(12px)
- Opacidad:       0.92
- Transición:     200ms cubic-bezier(0.23, 1, 0.32, 1)

## Uso
- Open Code: .opencode/themes/ai-nexus-core-chat.json
- Warp:      ~/.warp/themes/ai-nexus-core.yaml (ruta Windows: %APPDATA%\warp\Warp\data\themes\)
