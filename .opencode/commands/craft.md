Ejecuta el flujo completo de diseño con la skill `ui-ux-design-suite` para:

$ARGUMENTS

3. Construye con HTML semántico y Tailwind CSS, mobile-first y accesible.

6. Cierra con una autocrítica anti-slop y la lista de cambios pendientes.
